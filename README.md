# 🚀 NumStore - Portail Communautaire Apps & Jeux NumWorks

Store communautaire pour NumWorks ! Retrouvez tous les meilleurs jeux, émulateurs et applications indispensables pour votre calculatrice en un clic.

## 📚 Applications & Jeux Disponibles

Retrouvez sur notre portail une vaste sélection de projets open-source et d'adaptations exclusives optimisées pour NumWorks :

### 🛠️ Utilitaires & Cours
- **📚 NumNotes :** Créez et embarquez des fiches de révision, documents, présentations PowerPoint (slides), photos et emplois du temps directement sur votre calculatrice (par NumPlay / Mason363).
- **📝 Cheatsheet :** Affichez vos fiches de révision, cours et textes personnalisés directement sur votre écran (avec convertisseur d'images dédié). 
- **🤖 Matrice AI (v3.4) :** L'assistant de référence, spécialement adapté pour les filières STI2D et scientifiques.
- **🖼️ Gallery :** Visionneuse d'images, graphiques et schémas techniques.
- **🔒 Lock (Code PIN) :** Sécurisez l'accès à votre calculatrice avec un code secret au démarrage.
- **🎬 Video Player :** Lecteur vidéo haute performance (avec convertisseur vidéo en ligne obligatoire).
- **⏱️ NumVisuals :** Fonds d'écran animés avec horloge, chronomètre, minuteur, compteur ou texte personnalisé.
- **🧪 NumPowder :** The Powder Toy sur calculatrice, avec près de 200 éléments.

## 📲 Comment installer ces applications ?

1. Rendez-vous sur le [Portail NumStore](https://numstore.vercel.app/).
2. Choisissez votre application et téléchargez le fichier `.nwa` ou accédez aux releases.
3. Branchez votre calculatrice NumWorks en USB.
4. Déposez les fichiers directement sur la plateforme officielle [my.numworks.com/apps](https://my.numworks.com/apps).

## 📚 Applications & Jeux Disponibles

Retrouvez sur notre portail une vaste sélection de projets open-source et d'adaptations exclusives optimisées pour NumWorks :

*   **📝 Cheatsheet :** Affichez vos fiches de révision, cours et textes personnalisés directement sur votre écran (avec convertisseur d'images dédié).
*   **🤖 Matrice AI (v3.4) :** L'assistant de référence, spécialement adapté pour les filières STI2D et scientifiques / linguistiques.
*   **🐻 Five Nights at Freddy's (.nwa) :** Le célèbre jeu d'horreur adapté pour survivre aux caméras de surveillance.
*   **🏃 Subway Surfers (.nwa) :** Un *endless runner* ultra fluide pour esquiver les obstacles.
*   **🍄 Super Mario 64 (.nwa) :** L'exploit technique du moteur 3D culte de la Nintendo 64 sur calculatrice.
*   **🖼️ Gallery :** Visionneuse d'images, graphiques et schémas techniques.
*   **🎮 NumPlay Hub :** Le regroupement ultime de jeux (Balatro, Celeste, Hollow Knight, Minecraft, etc.).
*   **🔒 Lock (Code PIN) :** Sécurisez l'accès à votre calculatrice avec un code secret au démarrage.
*   **🍓 Celeste :** Le jeu de plateforme indépendant acclamé, jouable en version PICO-8.
*   **🎬 Video Player :** Lecteur vidéo haute performance (avec convertisseur vidéo en ligne obligatoire).
*   **👾 PeanutGB & Nofrendo :** Émulateurs complets pour lancer vos ROMs Game Boy (GBC) et NES avec son et sauvegarde.
*   **⛏️ Numcraft :** Un monde style Minecraft en Rust par la communauté. ( il est fait a la main lui )

Précision : tout les créateurs sont créditer sur le site.

## 📲 Comment installer ces applications ?

1. Rendez-vous sur le [Portail NumStore](https://numstore.vercel.app/).
2. Choisissez votre application et suivez le tutoriel de téléchargement.
3. Branchez votre calculatrice NumWorks en USB.
4. Déposez les fichiers `.nwa` directement sur la plateforme officielle [my.numworks.com/apps](https://my.numworks.com/apps).
